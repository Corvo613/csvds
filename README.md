# Client-Side Vulnerabilities Demonstration Stand

Приложение предназначено для практического ознакомления с некоторыми частыми клиентскими уязвимостями и механизмами безопасности.


### Развертывание стенда на MacOS

```
brew install python
git clone https://github.com/Corvo613/csvds
cd csvds/
git checkout localdev
chmod +x setup.sh
./setup.sh
```
